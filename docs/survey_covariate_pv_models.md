# 面向 15 分钟日前光伏功率预测的协变量感知时序模型：机理、证据与设计含义（综述）

日期：2026-10-08　范围：Reverso（2602.17634）、TiRex（2505.23719）两篇零样本基础模型的机理，以及 2023–2026 年关于
**已知未来协变量（NWP）如何进入深度预报模型**、**序列混合器选型**、**PV 场景实践与考核口径**的文献。
检索与核实由 5 个并行视角完成（主流融合机制、骨干消融、PV 实践与中国电网细则、批评与方法论、两篇论文的代码级细节）；
所有 arXiv 编号均在 arxiv.org 核对过标题，未能打开的条目标记为 [unverified] 且不引用其内容。

## 摘要

Reverso 与 TiRex 都是单变量、零样本的时序基础模型：前者用多尺度输入 + 门控长卷积与 DeltaNet 交替的混合骨干 + 注意力读出头，
2.6M 参数；后者用 sLSTM 骨干 + 连续 patch 掩码（CPM）+ 多 patch 分位输出，35M 参数。两者都不接受协变量。
把它们迁移到带 NWP 的 PV 日前预测时，文献给出的方向比较一致：（1）已知未来协变量必须在预报时刻位置对模型可见，而且输出侧注入
的贡献最大（ChronosX 消融：输出侧 0.182 vs 输入侧 1.035 相对 WQL）；（2）调制 / 门控优于直接相加；（3）没有迫使模型使用协变量的
训练信号（掩码、增强）时协变量几乎无效；（4）NWP 有误差时协变量模型可能比纯历史模型更差，训练期整通道 dropout 能把退化减半；
（5）PV 上实例归一化（RevIN）受夜间零值干扰，容量归一化 + 晴空 / 太阳高度角特征 + 白天掩码是更稳的做法；（6）混合器之间的差异
（2–5%）小于训练配方（CPM、分位损失、上下文长度、数据）与协变量本身带来的差异（PV 上 60% 量级），且在不同输入条件下排名会翻转。
结论用于指导 M8 模型的设计与变体矩阵。

## 1. 引言与研究问题

- **RQ1**：已知未来协变量（NWP）应在何处、以何种方式融入 patch 式序列模型？有无消融证据区分融合位置与融合方式？
- **RQ2**：对 15 分钟分辨率、192 步（2 天）地平线、强日周期的 PV 序列，sLSTM / DeltaNet / 长卷积 / 注意力哪种混合器更合适？
  「状态跟踪」是否重要？
- **RQ3**：PV 场景有哪些被证据支持的专属实践（归一化、夜间处理、NWP 偏差校正、概率输出、多站训练、考核口径）？

## 3. 两篇论文的机理（代码级）

| | Reverso（MIT） | TiRex（NXAI Community License） |
|---|---|---|
| 输入 | 2048 点上下文，C=4 个尺度通道（2^(c−1)·L 点按步长下采样；公开权重为 C=1），逐通道 min-max 到 [0,1] | NaN 感知 z-score，32 步不重叠 patch，拼 NaN 掩码 → 残差块 → d=512 |
| 骨干 | 门控长卷积（FFT 循环卷积，kernel = 序列长）与 DeltaNet（S_t = S_{t−1}(I − βkkᵀ) + βvkᵀ，4 头，q/k L2 归一，短卷积 k=4）交替 ×8，ReLU MLP ×4，LayerNorm 后置；中间层把末位隐状态加到首位（state weaving） | sLSTM ×12（指数门 + 稳定器 m，f 门裁到 15，逐头块对角递推，组归一化），SwiGLU FFN，RMSNorm 前置 |
| 输出 | 注意力读出头：q = W_q(W_L x)，对编码序列做单头注意力，线性到 p=48 步，自回归滚动 | 每个 token 一个残差块 → 9 分位 × 32 步；未来 patch 作为 NaN token 一次前向全部给出（不回灌预测值） |
| 损失/训练 | 未归一化空间 MAE，NaN 掩码；AdamW 5e-4 WSD；下采样 / 幅度调制 / 翻转 / 截断 / mixup；合成 GP 数据 | 每个 token 的 pinball（下一 patch 为目标）；CPM：c∼U{1..5} 块、p∼U(0,0.25) 比例的连续掩码；幅度调制 / 截断 / 尖峰 |
| 消融 | Conv+DeltaNet 0.725 MASE 最好；注意力读出头 +2%；GLA / 注意力最差（Table 15） | sLSTM 0.411 CRPS vs Transformer 0.422 vs mLSTM 0.457；去掉 CPM + 多 patch 退到 0.445（Table 1） |
| 发布代码 | 仅推理；`reverso_torch` 纯 torch 可用 | 仅推理；`backend="torch"` 纯 torch sLSTM；训练与 CPM 未发布 |

两个仓库都没有训练循环；多尺度输入与 CPM 只在论文里。TiRex 的 CPM 对长地平线 CRPS 的贡献（−0.045）大于 sLSTM 相对
Transformer 的贡献（−0.017），这是后文 RQ2 结论的关键证据之一。

## 4. 分类体系与各分支

### 4.1 协变量融合机制（RQ1）

| 机制 | 代表 | 证据（能源 / PV 优先） |
|---|---|---|
| 同序列多通道 + 跨变量注意力，未来值放在地平线位置 | Chronos-2 [1]、TimesFM-3 [2]、COSMIC [3] | Chronos-2 fev-bench 协变量任务 skill 40.9→47.0；PV 冷启动 WAPE 16.1 vs 单变量 TiRex 32.0 [4]；COSMIC 无增强时协变量无效（0.710→0.709） |
| 表格 / PFN 回归，协变量为逐时刻特征列 | TabPFN-TS [5]、ApolloPFN [6] | fev-bench skill 34.1→42.5；PV 冷启动 WAPE 15.5（最好）；对简单协变量关系的拟合远好于 Chronos-2（0.0000 vs 0.0456 nMSE）[7] |
| 目标对协变量的交叉注意力（从零训练） | TimeXer [8]、CITRAS [9] | EPF：cross-attn 0.307 vs 直接相加 0.329；ERCOT 太阳能 nMAE 3.85→3.53；CITRAS KV-shift 0.172 vs 无 0.226、晚融合 0.195 |
| 冻结骨干上的输出侧注入 | ChronosX [10]、LightGTS-Cov [11]、CoRA [12]、UniCA [13] | ChronosX：仅输出侧 0.182、仅输入侧 1.035、两者 0.735（相对 WQL）；CoRA adaLN 0.278 vs 相加 0.314；UniCA 四种前/后置位置差 <0.004 |
| 编码器-解码器 + 显式未来流 + 门控选择 | TFT [14]、TiDE [15] | TFT 去变量选择 +4.1% P90；TiDE temporal decoder 逐步拼未来协变量，M5 0.611 vs 0.637 |
| 线性残差回归 | TimesFM XReg [16] | EPF MAE 6.73→5.34；不支持仅历史协变量 |

跨工作比较：三项直接消融融合位置的工作结论一致——只要地平线位置能看到已知协变量的未来值，前置 / 后置差别很小（UniCA），
但把协变量移出序列、放到输出投影前的「晚融合」会损失 13–16%（CITRAS），而仅在输入侧给协变量几乎没有收益（ChronosX）。
融合方式上，调制 / 门控 / 交叉注意力稳定优于直接相加（CoRA、TimeXer）。训练信号方面，COSMIC 表明没有协变量增强时模型学不会用
协变量；TiRex / PatchTST-FM [17] 的 CPM 消融（0.750→0.696）说明掩码本身就是迫使模型依赖外部信息的强信号。

### 4.2 序列混合器（RQ2）

| 工作 | 比较对象 | 结果 |
|---|---|---|
| TiRex [18] Table 1 | sLSTM / Transformer / mLSTM，同管线 | CRPS 0.411 / 0.422 / 0.457；长地平线 0.325 / 0.342 / 0.430；短地平线 Transformer 持平或略好 |
| Reverso [19] Table 15 | DeltaNet / Gated DeltaNet / 长卷积 / GLA / 注意力 / 混合 | MASE 总体 .732 / .730 / .735 / .753 / .750–.762 / .725；交替 Conv→DN 最好 |
| TempoPFN [20] | DeltaProduct 阶数、负特征值、位置编码 | 负特征值（状态跟踪开关）对 CRPS 影响 0.002；正弦位置编码使递推模型劣化 0.561→0.648 |
| FlowState [21] | 复数 vs 实数 S5、选择性步长 | 去掉复数特征值 +19% MASE；Mamba 式选择性反而更差 |
| PatchTST-FM [17] | 上下文长度、CPM 块长、数据配比 | 纯 Transformer 0.696 MASE，与 TiRex / FlowState 同档；作者结论：数据与训练配方而非结构驱动榜单 |
| 日前负荷 [22] | Chronos-2 / TimesFM-2.5 / TiRex | 注意力型 TSFM 优于 TiRex（MAPE 3.44 vs 4.03）；DLinear 最差 |
| ERCOT 太阳能 [23] | 微调 TSFM vs 协变量模型 vs LSTM | TimesFM 3.71、TimeXer 3.85（nRMSE 最好 5.82）、TFT 3.91、PatchTST 4.18、LSTM 6.71 nMAE |

收敛点：在仅有的两个带注意力对照臂的同管线消融里，递推 / 卷积混合器优于全注意力，差距在长地平线最大（5% / 1.5–3%）；
对角门控的并行扫描类（mLSTM、GLA、选择性 S6）在三个独立消融里都是非注意力臂中最差的；振荡 / 递推状态对周期信号有用。
张力点：短地平线与日前能源基准上注意力型 TSFM 持平或更好；多篇工作表明加入天气输入后骨干排名会翻转 [24][25]；混合器收益
（2–5%）与种子噪声、上下文长度、超参预算同量级 [26][27]。「状态跟踪」的理论结果（对角 SSM 与 Transformer 同在 TC⁰，
DeltaProduct 可解 S_n）[28][29] 与预报精度之间没有任何工作建立因果联系，TempoPFN 的直接消融给出零效应；对带时间编码的
15 分钟 PV 序列，所需的「状态」只是相位与幅度，理论差距不构成选型依据。

### 4.3 PV 场景实践与考核口径（RQ3）

| 实践 | 证据 | 效应 |
|---|---|---|
| 归一化 | NWPsolarNet（CIGRE 2026，仅摘要）；CycleNet 附录 [30]；PV-Client [31] | 晴空比尺度 −4.0% MAE vs 装机容量；RevIN 在 Solar-Energy 上劣化（0.250 vs 0.208），但在日长窗口的 PV-Client 上有益——窗口跨夜间零值时 RevIN 不稳 |
| 夜间处理 | Yang 2020 [32]；Hoff & Perez 2012 [33] | 评测必须剔除夜间；含夜间会按分母不同让相对误差变化 ±29–50% |
| 物理特征 | PhysTrans（IJCAI-26）；PINN [34] | 晴空残差分支 −5% MAE；pvlib POA + 温度降额 −15.5% RMSE（小数据）；带太阳几何输入的模型在 NWP 加噪下更稳 [35] |
| NWP 偏差校正 / 多源 | GMD 2026 [36]；HEFTCom2024 [37]；GEB [38] | QM + TPA-LSTM 削减 GHI 误差 >23%；加集合预报 +8% pinball，叠加两套确定性全球模式 <0.3% |
| NWP 质量主导 | [39][40]；R²Energy [41] | 观测天气换成预报天气 MAE +11–68%；暴雨日技巧接近 0；「整合策略 > 结构」 |
| 概率输出 | Mayer 等 2026 [42] | QRNN CRPSS 14.7% vs EMOS 11.1%；非交叉约束（NCQRNN / BQN） |
| 树模型基线 | HEFTCom2024；PVDAQ 15 min [43] | CatBoost 逐源 NWP 特征夺冠；LightGBM 白天 nMAE 4.50% < 全量微调 Chronos-2 4.59% |
| 南网考核 | 南方区域实施细则 2025-02 [44] | 日前准确率 = [1 − √(1/96 Σ((P_M − P_P)/max(P_M, 0.2·Cap))²)]×100%，≥65%；限电时刻用可用功率；三者均 <10% 装机的点可不纳入 |

其他区域口径（华北 2022：分母恒为开机容量、≥85%；内蒙古 2017：MAE 型；东北 2024：误差带 ±20/22/25%；西北 2024：单点 20% 限值、
三日权重 0.6/0.3/0.1）见 scratch 报告；Q/GDW 10588 与 NB/T 32011 原文 [unconfirmed]。仓库 `pipelines/nanwang_metric.py` 实现的
就是南网式（分母 max(P_M, 0.2·Cap)），与细则一致。

### 4.4 批评视角：什么时候协变量会伤害模型

- **协变量噪声**：负荷任务上微调 Chronos-2 在 NWP 噪声 λ=1 时误差 +47%，λ=5 时 +329%，在 λ∈[1,5] 之间跌到自己不带协变量的版本之下 [22]；
  LightGBM 干净时最好但退化最快，序列模型在中等噪声处反超 [35]。训练期随机清零整条外生通道可把退化大致减半 [45]。
- **TSFM 忽略或被协变量伤害**：建筑能耗上 TimesFM 带协变量 2.13 vs 单变量 1.60 RMSE；Ridge / RF 优于全部 TSFM [46]。
  fev-bench 发现仅历史协变量会持续劣化 TabPFN-TS [47]。
- **评测泄漏**：R²Energy 用 ERA5 代替 NWP；多数 PV-TSFM 研究用再分析或未说明的天气输入；NWP 超过 2 天的技巧部分是数据构造造成 [48]。
- **零样本 TSFM 在 PV 上不可用**：日前 nMAE 9–11%、nRMSE 15–17%，微调后才与协变量模型持平 [23]；LoRA 带协变量时劣于全量微调 [49]。
- **结构排名不稳**：回看窗口、超参预算、是否加天气都能翻转 SOTA 表 [24][25][26][27]。

## 5. 跨分支讨论

三条线索汇到同一处：协变量在 PV 上值 60% 量级的误差（[23] 9.25→3.71），训练配方值 7–13%（CPM、分位损失），混合器值 2–5%，
而且后两者的排序在不同输入条件下会变。因此一个 PV 协变量模型的设计优先级应是：地平线位置可见的 NWP + 输出侧注入 →
迫使使用协变量的掩码训练 + 对 NWP 噪声的 dropout 鲁棒性 → 物理归一化与夜间掩码 → 最后才是混合器选型，而混合器必须在协变量
打开的条件下重新选、用多颗种子比较。Reverso 的 DeltaNet 在这个框架下有一个额外的机理理由：delta 规则等价于在上下文里做键值在线回归，
键 = NWP 特征、值 = 实测功率，未来 token 以自身 NWP 做查询即得到近期偏差校正后的映射——这正是 4.3 节「NWP 偏差校正」的在上下文版本，
但它只是假设，需要 b4_no_nwp / a4_deltanet_only 这类消融来检验。

## 6. 开放问题

1. 没有任何研究把业务 NWP（含偏差）作为未来协变量喂给 TSFM 并与再分析做对照；NWP 偏差校正从未在 TSFM 内部实现。
2. 原生多变量 TSFM（Chronos-2、TimesFM-3、COSMIC）都没有消融融合位置或跨变量注意力。
3. 没有研究在 15 分钟、96–192 步、带 NWP 的条件下隔离递推与注意力的差异。
4. 晴空指数 / 容量 / RevIN 三种目标归一化没有受控比较。
5. 中国多源确定性 NWP（EC/GFS/GDFS 三套）的组合价值只有集合预报的类比证据。

## 7. 结论（逐条回答）

- **RQ1**：把 NWP 的未来值放在地平线 token 里、并在输出头侧按步再次注入；融合深度本身影响小，但「不在序列里」会损失 13–16%；
  用门控 / MLP 融合而非相加；配合 CPM 与协变量 dropout。证据等级：三项直接消融一致，PV 上无直接消融（中等置信）。
- **RQ2**：在同参数量级，Reverso 式长卷积 + DeltaNet 交替与 sLSTM 都优于全注意力，但差距 2–5% 且随输入条件翻转；
  状态跟踪不是选型依据。推荐以混合骨干为基线、注意力与 sLSTM 为对照，在协变量打开、多种子下比较。证据等级：中等。
- **RQ3**：容量归一化（避免 RevIN 的夜间问题）、晴空功率与太阳高度角作为输入、损失与评测剔除夜间、分位输出 + 非交叉约束、
  树模型作为必跑基线、验证必须用业务 NWP；南网日前口径分母为 max(P_M, 0.2·Cap)。证据等级：实践一致性高，受控实验少。

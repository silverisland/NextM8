## 历史复现与兼容

归档 YAML 的模型、训练、输出目录和预处理数值保持原样，避免混淆已有实验。
平滑方式是中心算术均值：窗口 W=2k+1，首尾各 k 点不处理；
窗口有缺测时保留当前点，不做部分窗口平均。历史与目标分开处理。
历史平滑应用于训练和推理；目标平滑仅用于训练损失；评估真实功率保持原值。

现行代码已移除平滑实现。旧配置若两个窗口均为 1，可兼容加载，并在新保存的配置中移除该空操作块。
实际开启过平滑的 s 系列配置/权重会明确拒绝加载；复现时须使用对应历史 Git 版本，
不能直接删除这些旧权重配置中的平滑字段后宣称等价。归档 YAML 和已有实验产物保持原样。
EMA 和 early-stop 的指标平滑设置与 PV 平滑无关，保持不变。
